## 1. 用户纠正后的边界

本设计吸收用户当前两次明确补充：保留主机 SSH、SFTP、MCP 和主外框布局；数据库编辑区、按钮、Schema 树、菜单、右键菜单、快捷操作、预览、导入导出等都允许重新设计，只要有合理理由。此前将“保留外框”解释为“数据库内部也尽量不动”过于保守，此解释不再适用。

### 不改变

- `TitleBar` 的位置 / 尺寸 / 品牌；现有主题与设置、窗口行为。
- 外层 256px 连接保险库、主工作标签、48px 工具 rail 的组织；原有收起、连接详情、分组与账户功能。
- 主机 SSH 认证 / 连接 / 终端、多机、SFTP、隧道、监控与 MCP 工具 / 权限 / 服务。
- AI 面板的外层位置与主机模式；只允许增量扩展数据库上下文和已批准工作流。
- 真实凭据、生产数据库、已有 profile 和原有加密 key。

### 可以重做

- `DbWorkbench` 内部对象导航、查询 / 对象 / 任务标签、编辑器 / 输出布局、预览抽屉。
- 数据库上下文内所有按钮层级、菜单 / 右键菜单、快捷键、对象搜索与元数据层级。
- 结果 / 表数据 / 对象源码 / 结构展示；现有编辑、比较、ER、生成 SQL、复制、历史、片段、导入导出与迁移的入口与组织。
- 原始操作仍需保留或有更清晰等价入口，不因改版无故删除。新的复杂结构重建、备份、完整大图等独立专项不暗中扩张。

评审稿没有修改上述产品文件。所有页面是明示示例，不访问真实连接，不调用模型，不读取文件，不写数据库，不保存 secret，不改系统剪贴板。

## 2. 设计系统：沿用现有风格，不另造品牌

- Inter 界面字体、Geist Mono 代码 / 数据字体；中文走系统字体回退。
- 外框 48px titlebar、8px body 间距、6px 卡片、现有胶囊按钮、细边框与阴影层级。
- 内部紧凑工具体验：主动作 29–30px，次级图标 26px，常规行高 36px；密度可调。不是大卡片仪表盘。
- 成功 / 风险 / 错误取现有 semantic tokens；品牌 SVG 与图标取 Catio 本地资源。

原型顶端的“场景 / 设计说明 / Tweaks”只属于评审，不会作为新的全局产品导航。模板数据显式写“示例”，不伪造耗时、影响行数、真实计划成本或模型回复。

## 3. 布局选择

### 推荐 A：对象导航 + 主工作区 + 按需预览

在原主工作卡片内：

1. 连接 / 目标与数据库动作头部。
2. 左侧数据库对象树（默认约 216px，可收起 / 调整）。这是数据库内部导航，不改变外层连接保险库。
3. 内部标签：查询、固定对象、临时预览、分析、数据任务。
4. 查询页：目标 / 会话 → 编辑动作 → 代码 → 可拖分隔 → 输出。
5. 完整值、对象结构 peek 与菜单按需出现，不强制常驻第三栏。
6. AI 仍在现有右侧全局面板位置，不再造第二套数据库聊天栏。

理由：保留 Catio 使用习惯，将“找对象 → 写查询 → 看结果 → 后续操作”连成工作流，避免再增一层全局模块导航。

B：编辑器 62% / 对象树较窄，适合长 SQL；C：编辑器 28% / 结果优先，适合数据浏览。只是内部比例，不改主外框。默认 A 可拖动并记住数据库局部布局；正式持久化仅安全偏好，按用户 / 工作区隔离，不写 SQL 或 secret。

## 4. 各区域改造与理由

| 区域 | 设计 | 理由 / 约束 |
|---|---|---|
| SQL 代码编辑区 | 常驻“运行当前 / 选中、分析、格式化、保存”，其余进更多 / 右键；运行当前、选中、脚本明确区分 | 解决猜图标与误跑整脚本；选择为空禁用选中运行。语句范围需实际 parser 契约，不靠文本正则 |
| 补全与帮助 | namespace / 对象 / 类型 / 约束来源可见；复合 JOIN / 参数字段跳转；结构 peek 不离开代码 | 提示真实字段，不拍平同名表，未知 / 预算耗尽不猜；沿用 CodeMirror，原型 textarea 不是替代品 |
| 对象树 | namespace → 表 / 视图 / 函数 / 程序 / 引擎原生对象；逐层懒加载；搜索结果保留完整限定名 | 缩短定位流程，不强迫先展开所有库；加载 / 失败 / 截断 / 成功空库有不同状态 |
| 对象预览 | 单击临时预览，双击 / 固定保留；编辑时自动固定，脏草稿 / 活动事务阻止覆盖或关闭 | 减少标签堆积，同时不丢工作；完整身份必须是 tuple，含点号名称不串号 |
| 菜单 / 右键菜单 | 浏览、查询 / 数据、维护分组；选中对象 / 语句 / 行的不同菜单 | 保留当前目标 snapshot；不是失焦后读旧 selection。危险操作独立确认，未知 capability 不能假可用 |
| 快捷操作 | 数据库内命令面板；对象定位、打开查询、分析、数据工具、历史片段 | 常用操作可键盘发现；只在当前数据库 workbench 生效，不劫持 SSH / SFTP / IME |
| 数据网格 | 查询输出与可编辑表分开；服务端筛选 / 排序、完整值与原始类型、精确身份 / 并发保护 | 不把当前页本地过滤叫整表筛选；不混 NULL / 空串 / 空 BLOB；稳定主键缺失时禁止不可靠写入 |
| 表 / 对象展示 | 数据、字段、索引 / 约束、DDL / 源码同对象下统一 | 减少独立入口与跳转；复用现有结构编辑、ER、复制与管理，不擅自移除 |
| 更改草稿 | 本地更改条 → 差异 / 目标 / 权限预览 → 确认 → 回执 / 刷新 | UI 草稿不等于写入；更新失败或刷新失败保留确知状态，未知结果不自动重放 |
| 查询分析 | 节点图 / 树、概要、原始结果、源 SQL 联动 | 不编造成本 / 行数，不用 select_id 冒充 cardinality；默认不执行的 EXPLAIN，ANALYZE 独立风险门禁 |
| 导入 | 来源目标 → 映射 → 完整预检 → 执行 / 核验 | 从散落按钮形成连续流程；样本通过不代表整文件有效；精确数值 / binary / 复杂类型要保真 |
| 导出 | 当前页 / 选中 / 完整结果范围先确认；格式 / 快照策略 / 类型预览 | 避免只导当前页却称全量；浏览器下载与 Tauri save 使用不同落地方式 |
| 迁移 / 比较 | 原工具保持入口，明确源与目标、键、类型、暂存与覆盖策略 | 保留已有能力，5,000 行窗口明示；流式 / 一致性 / 全范围 sync 仍需后端补齐 |
| 数据任务 | 数据库局部面板：执行 ID、阶段、确认量、取消回执、未知结果核验 | 非新的全局调度系统；页面关闭不是取消，恢复只对实现了幂等检查点的任务开放 |

### 快捷键原则

保留现有 Alt+Enter 运行、Ctrl/Cmd+Space 补全、Tab snippet、Ctrl/Cmd+C 值复制及当前搜索 / 格式化习惯。数据库命令面板的具体组合先检查全局冲突再确定；原型 Ctrl+Shift+P 仅作评审示意。新增或变更必须支持 macOS 显示、IME、焦点作用域、配置兼容，不用“全局监听一个快捷键”覆盖主机。

## 5. 专用工作区不是 SQL 控制台换标题

- **MongoDB**：数据库 / 集合 → 文档 Grid / Tree / Extended JSON、原生筛选 / 排序、索引。保真 `_id` 类型和版本保护；不依据同形字符串 / reserved wrapper 推断原始 BSON。
- **Redis**：db / key → 按 String、Hash、List、Set、ZSet、Stream、JSON 展示；TTL、消息、Group、Pending 与批量选择。raw key / bytes 身份有界读取，不靠截断文本定位。
- **Elasticsearch**：索引 → 文档 / Query DSL、Mapping、Settings、Alias；文档 `_id` / `_seq_no` / `_primary_term` 与正文分离，冲突不自动覆盖。
- **DuckDB**：当前库与已登记 CSV / JSON / Parquet 文件；登记 / 授权 → schema 预览 → 生成查询 / 导入落表。Web 令牌所有权和清理，不接受任意后端文件路径。

正式工作区由真实连接的 engine / profile / capabilities 决定，**不是让同一连接随便切协议**。原型顶部场景选择只是展示不同连接场景。能力不存在时给出原因，不用灰按钮掩饰未实现。

## 6. 数据库 AI：继续复用现有面板

必要对象 / SQL / 计划选择 → 准备上下文 → 建议与依据 → 应用工具预览目标 / 差异 / 风险 → 用户批准 → 实际执行 → 执行回执 / 读回。模型生成的“成功”不当回执。

- 对话标签和连接绑定；切目标使旧预览 / 审批失效。
- 元数据失败保留草稿，不发送缺失结构，取消阻止迟到发送。
- 只发送必要授权结构，不默认整库，不发送 secret；结果 / 注释视为不可信数据。
- 宿主模式、MCP 工具授权与已有 SSH 文件操作语义不被数据库改版改变。
- 写入结果未知或 DDL 不能保证回滚时明示，不能自动重试。
- 真实模型样例通过不等于整个维护能力完成；原型 AI 字样全部是“示例建议 / 非模型调用”。

## 8. 交付与保护门禁

### 原型门禁

- 页面以模拟状态验证单击 / 固定、菜单、值预览、查询输出、导入步骤、导出范围、任务取消、专用场景、AI 审批。
- Dawn / Amber / Grove；1500×950 和 1100×800 至少检查布局，窄窗只收内部树，不移动外框。
- 无浏览器 error / warn；没有数据库 / 模型的 fetch / XHR / IPC；外部资源仅本地 Catio CSS / 字体 / SVG。
- 所有示例已标，不宣称原型是真实查询或测试通过的产品实现。

### 实现门禁（用户评审通过后）

1. 批准此稿 / 修改点，再形成增量实现计划；仅数据库组件和必要 services / driver 扩展。
2. 优先现有 React / CodeMirror / DataGrid / token / error / manager；不引入大型新库来换壳。
3. 为每个阶段建立用户可见场景：新的入口 → 操作 → 真实反馈；不仅纯函数测试。
4. desktop / Web 接线与权限分别验证；未设置 env gate 的 skip 不能当真实引擎通过。
5. 原 SSH / SFTP / 隧道 / MCP / Agent 宿主和框架测试保留，不削弱；数据库各功能入口有迁移清单。
6. 中英与三主题、键盘、IME、undo、长 SQL / 大结果预算、连接切换、取消、卸载、脏草稿与事务保护。
7. 保留用户 `capabilities.json` 原有改动、按暂存审计、逐逻辑增量中文 commit。生产 / 安装版不部署不重建。
