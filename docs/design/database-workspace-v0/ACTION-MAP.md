# 数据库动作归属与统一布局

## 用户补充要求

在推荐 A 的已批准边界内，数据库界面和功能尽可能向固定 DBX 基线对齐；优先让改进能在界面上被看到。用户对第一版截图进一步指出：新建查询 / 数据对比入口重复，事务、查询执行、布局控制散落在多排，按钮样式不统一。

本轮以“**每个动作有一个主入口、每种状态有明确归属**”修正设计。不是继续往工具栏堆按钮。右键菜单 / 快捷键保留必要的上下文访问，但不能再复制一条常驻的全局操作栏。

## 信息层级

```text
对象资源管理器                  文档标签（查询 / 表 / 视图 / ER / 比较）
连接名 · 刷新对象树 · 收起       运行 ▾  分析  格式化  保存  更多  |  事务状态 ▾
新建查询       工具 ▾            连接 / Schema  |  行上限 / 超时  |  面板布局
搜索 / 可见性过滤               SQL 编辑区
对象树                         结果 / 执行记录 / 执行计划
                               数据工具条 · 网格 · 按需记录侧栏
```

移除原数据库主区顶部重复的“新建查询 / 数据对比 / ER / 快捷操作”整排；欢迎页只做说明与快捷键提示，不再重复创建三组操作卡片。

## 唯一主入口

| 动作 | 常驻或展开后的主入口 | 约束 |
|---|---|---|
| 新建查询 | 对象栏左上按钮 | 不能再出现在主区顶部和欢迎页按钮中；Schema 右键保留带 namespace 的上下文动作 |
| 数据对比 / ER / 命令面板 | 对象栏“数据库工具”菜单 | 保留已有能力门控；Ctrl/⌘ Shift P 打开同一个命令面板 |
| 刷新对象 | 对象栏连接标题旁“刷新对象树” | 明确只更新元数据，不冒充查询重执行或会话重连 |
| 当前语句 / 选区执行 | 一个动态运行主按钮 | 选区存在时执行选区；实际选区丢失时不得扩展为整段 SQL |
| 整个脚本执行 | 运行按钮旁的“运行选项”菜单 | 必须显式选择，保留 Alt+Shift+Enter；不再同时出现在“更多操作” |
| 分析 / 格式化 / 保存 | 同一查询工具栏 | 同一高度、圆角、图标尺度；执行为唯一高强调动作，其余使用低强调样式 |
| 查找替换 / 结构速览 / SQL 文件 / 清空 | 查询工具栏“更多操作” | 复用既有动作和确认流程；不再复制运行 / 保存 / 格式化 |
| Begin / Commit / Rollback / 重连 | 一个“事务状态”菜单 | 状态来自真实会话，错误保持可见；独立物理会话、能力门控、busy 与重连确认不变 |
| 连接 / Schema / 行上限 / 超时 | 紧凑的查询上下文栏 | Schema 只有一个可编辑控件，不再同时显示一份重复值 |
| 上下 / 左右分栏、最大化 | 上下文栏右端的视图控制组 | 不与业务动作混排；切换不重建编辑器和结果状态 |
| 结果 / 执行记录 / 执行计划 | 常驻输出面板 | 计划只显示自己的源 SQL；不混入上一次结果的行数 / 耗时 / 定位按钮 |
| 筛选 / 排序 / 列显隐 / 刷新结果 / 导出 / 记录 | 数据网格工具条 | 与元数据刷新、事务重连区分；记录以非模态侧栏显示，选中行与记录导航联动 |

## 表对象工作区

```text
Schema.表名 · 引擎
数据 | 列 | 索引 | 外键 | 触发器 | DDL
当前视图的工具栏：筛选 · 匹配数量 | 添加列 / 复制 DDL · 刷新结构
数据网格或元数据内容（不再次嵌套“结构”导航）
```

- 对象页签支持方向键 / Home / End、明确的 tab / tabpanel 关系；数据网格与已访问结构组件切换时保持挂载，表对象身份改变时隔离旧响应和确认内容。
- 添加列仅在列视图出现；索引 / 外键 / 触发器的删除仍是对象行级动作，保留名称确认和实际能力门控。Mongo / ES 不显示 SQL DDL / 外键 / 触发器；Redis 保留 keyspace。
- 筛选只查已加载元数据，不执行 SQL；分别保持各视图的筛选词，数量表示匹配条目 / 返回条目，不冒充全库或全部类型能力。
- “刷新结构”只刷新当前对象元数据；与对象树刷新、数据网格刷新区分。加载 / 失败 / 空结果分开，失败不退演示数据；正在确认或执行变更时不能刷新掉上下文。
- DDL 当前为元数据重建稿，必须显示并非数据库原始 DDL、非备份 / 迁移脚本的提示；加载失败不允许复制旧内容，复制成功仅在 clipboard 回执后显示。
- 结构变更后仍由网格唯一刷新入口重读行数据和列键元数据，不能拿新行配旧表头；元数据读取失败时禁用已有行编辑。不强制刷新而丢弃网格草稿。
- 多语句结构变更显示已经确认成功的语句数；中途失败不允许直接重放整个批次，不称已回滚。索引 / 外键 / 触发器的在途操作同样登记忙碌状态，避免关闭或重复确认。

## 导入 / SQL 导出向导

- 导入主入口仍归表数据网格；整库 / Schema SQL 导出仍归 Schema 操作菜单，不加新的全局导入导出工具条。
- 导入：文件预览 → 映射与模式 → 确认操作 → 执行回执。没有实现的无表头、编码、工作表选择不显示空选项。预览只读，展示样本范围、跳过列、NULL / 空字符串 / HEX，执行按钮仅出现在确认页。
- 目标 metadata 失败需可见并可重试；未就绪不得进入确认。重复映射 / 重复来源名称不能执行；模糊匹配存在多个目标时不猜。替换数据需在确认页重输准确表名，并由后端检查能力。
- SQL 导出：表与选项 → 确认操作 → 回执；筛选后的全选 / 清空不改其他选中项。确认页固定显式表清单，非法行数不默认为无上限。重建 DDL 的局限、内存组装和非一致性快照需可见。
- 文件选择 / 执行期间同步锁防重复触发，统一 portal 模态、焦点环与 Escape 处理；不向底层查询编辑器传播执行快捷键。真实请求结束前不能关闭，不展示没有后端支持的取消或百分比。
- 成功后不自动关闭、不保留可误点的第二次执行按钮。导入报错 / 回执未知后，先核验数据库再新建操作，不直接重放；刷新失败不改写已成功导入的回执。
- 桌面导出先选择保存路径，取消不读取导出数据；Web 走真实下载，文案为“已发起下载”而非“已保存到磁盘”。两者都显示对应结果，不把 Promise 完成或取消称为成功保存。

## 样式规则

- 保留 Catio 的 Inter / Geist Mono 与 Dawn / Amber / Grove tokens，不改 TitleBar、保险库、应用级标签、tool rail、SSH / SFTP / MCP。
- 数据库工具按钮统一为 28px 控制高度、4px 圆角、13–15px 固定图标；右键节点小触发器维持其树行密度。
- 只强调“新建 / 运行”等当前主操作，其他操作以低强调工具按钮 / 菜单呈现，不给每个动作套独立强调框。
- 窄宽度先收起次要文字，保留可访问名称、tooltip、图标宽度和键盘访问；不能压缩图标成小点。
- 样式限定在数据库组件类名下，不覆盖应用全局按钮或其他模块。

## 不靠按钮数量“超越”

差异化目标是更可靠、可理解的工作流：类型保真、执行范围明确、回执可核验、未知结果不重试、面板切换不丢状态。它们需要真实验证，不把原型、前端测试总数或几个样例宣称为完整 DBX 对齐。

本文件是动作归属契约，不是全部功能完成声明。实现、截图、验证范围与未完事项继续记录在 `IMPLEMENTATION.md`。
