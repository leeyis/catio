# 虫洞 0.2.1 接收重置复审

日期：2026-09-17。范围：接收页重置入口、会话与界面清理、重复文件接收、版本与交付。

## 原因与修复

解码器会记住已完成的传输，防止动态码持续播放时不断保存副本。相同传输需要重置会话后才能再次接收。旧入口只在“选项”中，且没有解除暂停或清除旧完成提示、引导状态。

接收页新增“重置接收”，先暂停提交并停止相机，再调用已有 JNI 重置等待解码线程退出；随后清空统计、进度、完成提示、引导及错误计数，解除暂停并恢复相机。已保存的文件与编码模式偏好不变。相机沿用已有缩放设置。选项中的重置复用同一方法。

保留现有无覆盖文件发布机制。同名文件自动追加 ` (1)`、` (2)` 等后缀，放在扩展名前；没有扩展名也会编号。一次会话仍只保存同一传输一次，只有主动重置才允许再次保存。

## 对抗检查

本轮自行复查调用链与差异，未使用额外评审代理。

- 暂停后重置必须真正恢复接收，不能只清空原生解码器。
- 完成提示、进度和引导必须同步清空，旧完成事件不能在新会话中重新出现。
- 相机停止提交后，JNI 必须等待旧线程退出，避免旧帧写入新会话。
- 连续重置、未完成接收时重置均可恢复；重置不调用文件删除。
- 重复播放不自动生成无限副本；主动重置后重复接收不会覆盖原件。
- 中英文按钮、权限/初始化状态与原主题保持一致。

未发现本次变更遗留的已确认阻断缺陷。
