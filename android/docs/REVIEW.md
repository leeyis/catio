# 虫洞 0.2.0 对抗评审

日期：2026-09-17。范围：Catio 桌面/服务端的安装配置门槛、文案及播放节奏，以及 Android 相对 0.1.0 的 UI、相机、解码和仓库整合。前版评审归档于 [REVIEW-0.1.0.md](REVIEW-0.1.0.md)。

## 方法与发现

使用 review-agent 的只读、缺陷优先流程检查完整改动与调用关系，再单独修复；没有使用额外评审代理。检查配置缺失/重复/无效、直接 RPC 绕过、SFTP 文件限制、暂停/切页/旋转、相机参数与焦点回调、帧所有权和队列压力、WebView 离线资源、文件名注入、文件操作与原件保留。

本轮发现并修复：

- **P2：macOS 安装配置写进签名包。** 改为在 `Catio.app` 旁读取/创建，AppImage 同样使用持久文件位置；只读目录保持关闭，由管理员放置配置。开关仅启动时读取，不覆盖已有文件。
- **P2：区域对焦恢复重复执行或过期。** 使用 generation 使 700 ms 回调和 3 秒保底恢复互斥，缩放/释放后旧回调失效；双指手势结束不再触发额外点按对焦。
- **P2：相机 HAL 不接受公开 FPS 与分辨率的组合。** 优选 30–60 fps 失败时恢复设备原帧率和焦点模式，避免整个预览初始化失败。
- **P2：发送页面语言与应用语言不一致。** 将 Android 当前语言传给本地页面，支持应用独立语言设置。
- **P2：底部导航文字与图标未对齐。** 实际截图复现，改为标签居中。
- **P2：横屏发送码图被底部导航裁切。** 按 WebView 可用高度限制正方形码图，并收紧横屏信息区域；仪器测试切换横屏后实际编码，验证四角均处于可见区域。

解码器在拷贝帧之前限制在途数量；ROI 扫描失败立即恢复全图，仍逐帧计算角点/透视，没有将旧透视矩阵套用到手持移动后的帧。上游 JNI 已具备自动模式锁定，本轮只调整首次模式探测顺序，未将已有能力计作提速收益。

## 验证

- 前端相关 5 组、40 项测试通过，覆盖隐藏/显示设置入口、不可通过直接切页显示隐藏面板、免责声明确认、口令解锁、SFTP 菜单、播放生命周期和 30 fps 调度；TypeScript/Vite 构建通过。
- Rust optical 单元测试和独立 server_optical HTTP/SFTP 集成测试覆盖关闭状态拒绝接口、会话隔离、撤销/取消、实际 5 MiB 边界与超限拒绝。
- Android Java 共 10 项单元测试通过；lint 无错误。
- Android 14 x86_64 模拟器 9 项仪器测试全部通过：实际桌面 WASM 图像经 JNI/OpenCV/fountain/Zstd 还原，Unicode 文件名、逐字节校验、重复帧去重、同名防覆盖、自动模式、合成透视倾斜、过载后恢复、软件链路计时、导航/暂停/重建、取消另存保留原件、离线发送与文件名 HTML 注入防护。
- 软件回环样例：32768 字节在 708 ms 内还原；这是小文件、2 核模拟器、排除相机的功能计时，不能作为物理链路吞吐或新旧性能比较。
- 首次仪器运行因模拟器未连接、第二次因系统尚未完成启动而没有执行测试；启动完成后全套通过。ATD 测试镜像默认禁用界面绘制，视觉检查时显式启用，与产品逻辑无关。

## 复审结论与边界

已确认的问题均已修复，没有遗留已确认的阻断缺陷。截图、构建输出、签名/对齐与 APK 校验信息存放在被忽略的 `artifacts/`，不会将常规构建产物提交源码仓库。

**200 KB/s 的 OnePlus 6 实拍目标尚未验证。** 用户提供旧版约 70 KB/s；没有连接这台手机，不能用模拟器、理论编码容量或 4K60 录像后电脑解码结果冒充手机实时结果。真实自动对焦、倾斜/距离容忍度、摩尔纹与吞吐仍需按 [PERFORMANCE.md](PERFORMANCE.md) 对照验收。

APK 为可安装的 debug 测试签名，包含 arm64-v8a / x86_64；最低 API 21，未逐机验证所有 Android 版本。源码位于 Catio 仓库 `android/`，上游编码资源已展平并保留许可证与 SHA-256 校验。
