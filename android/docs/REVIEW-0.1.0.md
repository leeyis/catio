# Catio Android 接收端对抗评审

日期：2026-09-16。范围：相对 CameraFileCopy `e143ebd16154f3db17fbfdf8d0da71b1b50678a4` 的本次 Android 改动，包括未跟踪的新文件；不修改相邻 Catio 中其他任务的改动。

## 评审方法

按 review-agent 的缺陷优先流程读取完整改动、调用关系、上游协议实现和对应测试，分开进行评审与修复。重点检查真实进度/速度、跨线程帧所有权、重复数据、模式切换、生命周期、文件发布、权限、WebView 和资源兼容性。未使用额外评审代理。

## 已修复问题

- **P1：Android 私有目录中硬链接发布失败。** 模拟器上的真实协议互通测试复现：OpenCV / fountain / Zstd 已恢复全部数据，但 `link()` 返回 EACCES，无法发布文件。改为 `renameat2(RENAME_NOREPLACE)`；老内核回退只在应用私有目录内串行检查目标后重命名。完成事件仅在发布成功后发出。增加 Android 重复接收同名文件测试。
- **P2：收集到 99% 时过早显示正在校验。** fountain 仍可能需要更多数据块，现改为“正在补齐最后的数据”，仅 native finishing 状态显示还原/校验。
- **P2：相机错误卡片高频重建。** 原轮询每 250 ms 替换重试按钮，会影响点击。现缓存卡片状态，只在状态变化时重建。
- **P2：发送页在 WASM 初始化前调用 resize。** Main.resize 会立即调用 native WASM 函数，导致初始化阶段异常。移除提前调用，交由上游 runtime ready 初始化；使用主线程编码器，避免不支持 OffscreenCanvas 的 WebView 反复回退加载。原 PWA service worker 由原生资源加载代替。
- **P2：发送页品牌替换丢失 WebGL 错误提示。** 保留原错误节点及默认消息显隐规则；文件名通过 textContent 显示，并拦截原上游包含文件名的 console 输出。
- **P2：发送页的上游样式覆盖品牌样式。** 原页面将 CSS 放在 body 中，插入 head 的品牌 CSS 被后面的旧 CSS 覆盖。视觉检查复现后改为在 body 末尾插入，增加 computed style 自动断言，确保去除旧渐变/阴影；菜单同步中英文，保留原有快速闪烁提示。
- **P2：初始化失败后的重试未重新启动解码器。** 重试路径补充目录创建与 native 初始化，可在临时存储/加载问题消除后再次尝试。
- **P2：Android 16 返回手势和最低 API 主题属性不兼容。** lint 检出并修复：改用 AndroidX 返回调度器，系统栏图标颜色通过兼容 API 设置。

接收写入、导出取消保留原件、中文/emoji 文件名使用 UTF-8 字节跨 JNI、后台线程持有独立帧副本、停止并 join 后销毁 decoder、网络权限关闭、文件共享范围限制等路径也已检查。

## 验证结果

- arm64-v8a / x86_64 原生核心与 debug APK 编译成功。
- Java 反馈逻辑：8 项测试通过，涵盖去重速度、暂停/重置、定位可信度、方向/距离/倾斜提示与未完成进度上限。
- Android 34 x86_64 模拟器：实际桌面 WASM 码图通过 JNI / OpenCV / fountain / Zstd 接收，文件逐字节一致，中文与 emoji 名称保留，重复帧不增大有效接收字节；自动模式通过。
- Android 仪器测试最终共 6 项全部通过：3 项接收协议/自动模式/同名防覆盖，2 项 UI 导航/取消另存/暂停/重建，1 项离线发送、四模式切换和文件名 HTML 注入防护。
- C++ 文件存储测试通过：Unicode、同名编号、路径清理、隐藏名称、空文件、5 MiB 高压缩文件、symlink 不覆盖、损坏/截断拒绝、IO 失败和临时文件清理。
- Android lint 无错误。剩余警告以原上游旧资源/兼容分支、可升级的依赖、英文复数和 launcher monochrome 建议为主，未通过 blanket suppression 隐藏。
- 已检查中文接收页的浅色/深色、横竖屏；修正了按钮默认阴影和亮画面上对焦提示的可读性。

最终汇总见 `artifacts/validation.json`。APK 的 v1/v2 签名验证、ZIP 16 KiB 对齐及所有 6 个 ARM64/x86_64 ELF 库的 LOAD 段 16 KiB 对齐检查通过。交付文件 SHA-256 见 `artifacts/SHA256SUMS.txt`。

复审结论：本次发现的问题已修复，没有遗留已确认的阻断缺陷；以下实测边界仍保留。
